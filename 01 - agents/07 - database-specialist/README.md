# database-specialist/

Agente especializado planejado para diagnóstico técnico de bancos de dados, compondo skills e MCPs autorizados. O exemplo QuickStore prevê análise de banco/código legado sem alterar dados.

## Escopo de diagnóstico
Pode inventariar metadados e dependências, analisar índices, consultas, desempenho e segurança, recuperar documentação autorizada e produzir achados com evidências, riscos e recomendações. Scripts podem coletar dados determinísticos; IA interpreta pontos complexos.

Operar em leitura por padrão. Distinguir observação de hipótese; não executar DDL/DML, migrações ou mudanças de permissões sem autorização específica, plano de reversão e validação. Dados de cada projeto permanecem isolados.

Base: especificação, seções 7, 20.1 e 20.6.
