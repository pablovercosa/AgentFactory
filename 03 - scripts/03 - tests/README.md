# scripts/tests/

Testes unitários, de contrato e regressão para scripts determinísticos. Cobrir entradas válidas e inválidas, limites, erros, efeitos colaterais, schemas e comportamento em condições de falha.

Executar em ambiente isolado com fixtures sem dados sensíveis. Fixar versão e dependências para resultados reproduzíveis; manter casos ligados à finalidade e às permissões declaradas no manifesto. Candidatos com falha ou regressão não devem ser publicados.

Base: especificação, seções 12.2–12.3 e 17.2–17.4.
