# templates/

Modelos reutilizáveis para iniciar agentes, skills, scripts e projetos conforme os contratos da Agent Factory. Templates são pontos de partida, não artefatos prontos para produção.

Substituir todos os placeholders; revisar dependências, versão, escopo de dados, permissões e custos; adaptar o formato nativo à versão instalada do executor; incluir testes; validar a saída antes de publicar. Não inserir credenciais reais nem configurar publicação automática.

Base: especificação, seções 10, 11, 12 e 18.
