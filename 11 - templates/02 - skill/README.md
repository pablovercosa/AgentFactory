# templates/skill/

Modelo de `SKILL.md` e manifesto próprio para criar skills atômicas, curtas, descobríveis, versionadas e avaliáveis. O manifesto registra dependências/projetos/políticas e não substitui frontmatter nativo exigido por cada executor.

Mover procedimentos longos para `references/`, código determinístico para `scripts/` e casos de avaliação para `tests/`. Validar descoberta nos executores-alvo; referenciar outra skill não garante carregamento automático. Publicar snapshot aprovado, não a árvore editável.

Base: especificação, seção 10.
