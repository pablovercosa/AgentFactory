# adapters/

Modelos de configuração gerada para Claude Code e OpenCode. Cada adaptador traduz o contrato portável do agente para os recursos e a sintaxe realmente suportados pela versão instalada.

Testar carregamento, modelo, dependências, permissões e compatibilidade; manter menor privilégio e não presumir equivalência entre executores. O artefato gerado deve poder ser reproduzido a partir do manifesto e revisado antes de distribuição.

Base: especificação, seções 11.1–11.4 e 13.2–13.5.
