# technical-documentation/

Skill para produzir documentação técnica rastreável, coerente com arquitetura, fontes oficiais e estado real do software. Deve manter exemplos úteis sem apresentar propostas ou protótipos como capacidades implantadas.

## Critérios
Identificar público e finalidade; citar versões e proveniência; separar decisão aprovada, hipótese, TODO e implementação verificada; manter contratos e limitações explícitos; revisar links, exemplos e riscos de dados sensíveis. Em documentação de instalação/operação, registrar pré-requisitos, validação e recuperação.

Atualizar changelog somente com mudanças realizadas e verificadas. Documentação não autoriza por si só a execução das operações descritas.

Base: especificação, seções 5, 6, 19, 21 e 23.
