# github-manager/

Skill para consultas e operações autorizadas no GitHub — repositórios, branches, issues, pull requests e histórico — respeitando o escopo do projeto.

## Procedimento
Verificar repositório e estado atuais; pesquisar issues/PRs existentes antes de criar; usar templates e convenções aplicáveis; distinguir leitura de operações que escrevem, fecham ou publicam. Confirmar destino, conteúdo e impacto antes de ações mutáveis. Registrar links/resultados verificáveis.

Não incluir tokens nos arquivos nem nas saídas. Publicação, merge, fechamento ou alteração remota requer aprovação adequada e plano para corrigir efeitos quando reversão simples não for possível.

Base: especificação, seções 5.3, 19 e 22.
