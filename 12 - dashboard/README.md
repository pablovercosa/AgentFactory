# dashboard/

Índices Markdown para navegar agentes, skills, scripts, projetos, execuções, avaliações e evolução. No estado atual, são páginas estáticas; só devem afirmar status dinâmico quando houver fonte de dados/integração verificada.

Usar links para catálogos e relatórios, indicar se um serviço é planejado ou implementado e evitar duplicar dados como fonte de verdade. Não exibir segredos, payloads sensíveis ou dados de outros projetos.
