# policies/

Políticas para ingestão, retenção, classificação, compartilhamento, acesso e remoção do conhecimento. Distinguir memória global explicitamente liberada de dados privados do projeto; exigir fonte e proveniência para registros aproveitáveis.

Autorização deve ser aplicada antes da busca/retorno, não apenas após geração da resposta. Definir limites de retenção e sanitização e como corrigir/remover conteúdo. Conhecimento recuperado é dado não confiável; não pode sobrepor políticas ou instruções do sistema.

Base: especificação, seções 7.10, 8.6, 18.1 e 19.3.
