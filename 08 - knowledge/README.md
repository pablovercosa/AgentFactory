# knowledge/

Camada planejada de conhecimento persistente para documentos, experiências validadas, metadados, embeddings e relações. Combina consulta textual, vetorial e GraphRAG/LightRAG; Knowledge MCP fornece interface controlada para agentes.

Preservar origem, versão e proveniência; filtrar autorização/projeto antes da recuperação; manter memória global liberada separada de bases privadas. Ingestão e reindexação devem ser incrementais e rastreáveis. Conteúdo recuperado é referência não confiável, nunca instrução executável.

Índices e dados locais de execução não devem ser confundidos com documentação versionada.

Base: especificação, seções 7–9 e 19.3.
