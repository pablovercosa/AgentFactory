# schemas/

Schemas versionados para validar documentos, manifestos, dados ingeridos e contratos de entrada/saída usados na camada de conhecimento. Devem permitir verificar estrutura e metadados antes de persistir ou devolver informação.

Mudanças requerem versão, compatibilidade explícita, casos válidos/inválidos e plano de migração quando aplicável. Validar proveniência, identificadores de projeto e campos de classificação/acesso; não aceitar que conteúdo documental altere a política de autorização.

Base: especificação, seções 7.3, 7.4, 9.4 e 18.2.
