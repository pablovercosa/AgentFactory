# docs/configuration/

Documentação das opções e contratos de configuração da plataforma, manifestos de projeto e políticas de roteamento, cotas, Bridge e JEV. Informar versão, tipo, valor permitido, padrão, escopo e componente consumidor.

Distinguir formatos próprios da Agent Factory de configurações nativas Claude Code/OpenCode. Usar placeholders, nunca credenciais reais; credenciais permanecem em `.fontes/Secrets/`. Explicar fallback/custo, privacidade e compatibilidade e validar contra schema antes do uso.

Base: especificação, seções 10.2, 11.1, 13.4 e 18.2.
