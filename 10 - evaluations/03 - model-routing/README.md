# model-routing/

Avaliações de escolhas de executor, provider e modelo em tarefas representativas. Comparar qualidade, compatibilidade, latência, custo, limites e comportamento de fallback usando as mesmas entradas e configuração versionada.

Resultados orientam a política do Model Router; não presumir que assinatura de um executor autorize uso de API separada ou cobrança adicional. Registrar modelos testados e condições, sem credenciais. Fallback pago permanece desativado sem autorização explícita.

Base: especificação, seções 13.1–13.5 e 17.2.
