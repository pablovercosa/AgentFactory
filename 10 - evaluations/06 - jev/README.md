# jev/

Casos para calibrar JEV/TypeSafe em classificação estruturada, especialmente escolha entre rotas/skills/fonte já autorizadas. Medir acertos, falsos positivos/negativos, abstenções, escolhas fora da allowlist e estabilidade entre versões.

Separar decisões determinísticas de casos realmente ambíguos; calibrar critérios e limiares com dataset representativo. A saída probabilística não autoriza operações nem substitui controles humanos.

Base: especificação, seções 16.1–16.7.
