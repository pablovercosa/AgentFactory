# benchmarks/

Benchmarks reproduzíveis para comparar versões de agente, skill, script ou roteador sob as mesmas tarefas e condições. Registrar versão do executor/modelo, ambiente, dataset, baseline e método de cálculo.

Medir qualidade/correção e segurança junto a latência, tokens e custo quando relevantes; informar incerteza e limitações. Não aprovar uma versão mais rápida se houver regressão funcional ou de segurança. Manter resultados rastreáveis e sem dados sensíveis.

Base: especificação, seções 17.2–17.4.
