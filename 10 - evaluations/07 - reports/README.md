# reports/

Relatórios de avaliações concluídas, com versão/hash testado, executor/modelo, dataset, baseline, condições, métricas, evidências, regressões, limitações e recomendação.

Deixar claro se a avaliação foi aprovada, reprovada ou inconclusiva; recomendações não publicam componentes automaticamente. Sanitizar segredos, dados pessoais e conteúdo de projeto antes de compartilhar ou versionar. Relatórios devem permitir reprodução e comparação posterior.

Base: especificação, seções 17.2–17.4 e 22.1.
