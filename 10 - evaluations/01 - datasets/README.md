# datasets/

Casos versionados para avaliar skills, agentes, roteamento, JEV, cotas, delegação e serviços. Cada caso deve indicar origem autorizada, entradas, resultado/critérios esperados, versão e limitações do conjunto.

Remover credenciais, dados pessoais e conteúdo de projeto sem autorização; usar dados sintéticos quando possível. Evitar vazamento entre treino/calibração e avaliação final. Alterações no dataset devem ser rastreáveis para que comparações com baseline sejam interpretáveis.

Base: especificação, seções 17.2, 16.5–16.7 e 22.1.
