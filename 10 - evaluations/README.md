# evaluations/

Conjuntos de testes, benchmarks, calibrações e relatórios para comparar versões de skills, agentes, scripts e serviços. Medições devem ser reproduzíveis, com baseline, versão, executor/modelo, dataset e condições registradas.

Avaliar qualidade/correção e segurança antes de custo/latência; evitar que otimização de tokens esconda regressão. Propostas de evolução dependem de evidências e revisão. Remover segredos e dados pessoais dos datasets/relatórios.

Base: especificação, seções 17.2–17.4 e 22.1.
