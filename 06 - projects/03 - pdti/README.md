# projects/pdti/

Espaço do projeto de PDTI para manifestos e referências institucionais autorizadas sobre governança, infraestrutura, iniciativas e planejamento. Restringir o acesso a documentos e dados institucionais.

Cenário previsto: avaliar consistência de um pré-projeto, recuperar documentos permitidos, relacionar iniciativas/serviços/dependências e produzir relatório de riscos e lacunas. Conhecimento técnico genérico só pode tornar-se ativo global após revisão; textos ou dados restritos permanecem isolados.

Base: especificação, seções 18 e 20.3.
