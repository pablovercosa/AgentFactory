# projects/investments/

Espaço do projeto de investimentos e backtesting, com dados, configurações, manifestos e políticas financeiras isolados.

Cenário previsto: Execution Router seleciona script de backtesting aprovado; código calcula indicadores de forma determinística; agente interpreta tendências e limitações; avaliador verifica que ganhos de desempenho não escondem piora de risco. Registrar versões/hashes dos dados e artefatos usados.

Backtesting não autoriza ordens reais. Execução financeira, acesso a contas e uso de dinheiro exigem controles e autorizações independentes.

Base: especificação, seções 18 e 20.4.
