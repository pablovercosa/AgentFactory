# projects/custo-brasil/

Espaço do projeto de documentos fiscais brasileiros. Isolar dados fiscais e regras específicas; registrar fontes normativas oficiais, versão e vigência para que conclusões possam ser verificadas.

Cenário previsto: recuperar fontes versionadas; validar XML deterministicamente contra schemas aplicáveis; usar IA para interpretar discrepâncias com referências e limitações explícitas; produzir testes de regressão e submeter mudanças a PR/revisão. Interpretações não são parecer jurídico nem certeza legal.

Não compartilhar dados do projeto automaticamente com a memória global.

Base: especificação, seções 18 e 20.2.
