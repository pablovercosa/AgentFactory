# projects/quickstore/

Espaço de configuração e referências autorizadas do projeto QuickStore. O cenário de referência é uma análise de banco e código legado, sem alteração de dados.

Fluxo ilustrativo: resolver agentes/skills aprovados no Registry; recuperar documentação autorizada; usar scripts para inventário e metadados; recorrer à interpretação do especialista apenas para pontos complexos; apresentar achados com evidências, riscos e recomendações. Uma delegação Claude→OpenCode só ocorre se Bridge e permissões estiverem configuradas.

Não copiar dados de outros projetos. O exemplo não comprova que os agentes, MCPs ou serviços estejam implantados.

Base: especificação, seções 18 e 20.1.
