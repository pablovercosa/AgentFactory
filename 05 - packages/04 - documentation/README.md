# packages/documentation/

Pacote de modelos, skills e scripts para documentação técnica, relatórios e formatos de arquivo. Deve facilitar a produção reproduzível de entregáveis sem misturar conteúdo sensível de projetos.

Registrar fontes, versões e proveniência; diferenciar proposta, decisão aprovada, protótipo e implementação verificada. Exemplos devem usar placeholders; documentação operacional inclui pré-condições, validação e recuperação. Validar o formato final e manter evidências relevantes.

Base: especificação, seções 5, 19–23.
